# Alinita Partners Website

Static website ready for GitHub Pages.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Publish free on GitHub Pages
1. Create a new public GitHub repository, e.g. `alinita-partners`.
2. Upload the three website files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` branch and `/ (root)` folder, then Save.
6. GitHub will provide a free URL like `https://USERNAME.github.io/alinita-partners/`.

## Custom domain later
In GitHub Pages settings, add your domain under **Custom domain** and configure the DNS records at your domain provider.

## Before launch
Replace `info@alinitapartners.com` in `index.html` and `script.js` if you use another email address.

## Images
The current version uses Unsplash image URLs, so no image files need to be uploaded. For a premium launch, replace these with licensed/original hotel and real-estate imagery.
